# Actividad6
🐷 OINK – Sistema Inteligente de Ahorro

OINK es una aplicación desarrollada en Python y Streamlit que ayuda a visualizar y analizar los hábitos de ahorro de los usuarios. El proyecto combina análisis de datos, educación financiera y tecnología de voz en una interfaz sencilla y didáctica.

🚀 ¿Qué puede hacer OINK?
🏠 Inicio

Presenta el proyecto y explica de manera sencilla cómo funciona el sistema de ahorro.

📊 Dashboard

Permite cargar datos mediante un archivo CSV y visualizar información como:

💰 Ahorro total
📥 Cantidad de depósitos
👥 Número de usuarios
📈 Promedio de ahorro
📊 Gráficos de ahorro por usuario
📊 Frecuencia de depósitos
🧠 Índice de Comportamiento Financiero (ICF)

El sistema calcula un índice propio para analizar el comportamiento de ahorro.

El ICF utiliza tres factores:

Factor	Peso
💰 Ahorro total	40%
📥 Frecuencia de depósitos	30%
💵 Promedio de depósito	30%

Después, el resultado se clasifica en:

Bajo → Medio → Alto → Excelente

📌 El ICF utilizado en este proyecto es una fórmula creada para OINK con fines académicos y no corresponde a un indicador financiero oficial.

🎤 Tutor de Voz

OINK también cuenta con un tutor interactivo que permite:

🎙️ Hablar mediante el micrófono.
🌎 Detectar el idioma utilizado.
📝 Convertir la voz en texto.
🤖 Generar una respuesta relacionada con el proyecto.
🔊 Reproducir la respuesta en el mismo idioma.

Actualmente se contemplan español, inglés, portugués, francés, alemán e italiano.

🛠️ Tecnologías utilizadas
🐍 Python
🎨 Streamlit
📊 Pandas
📈 Matplotlib
🎤 SpeechRecognition
🔊 gTTS
🎙️ Streamlit Mic Recorder
🎯 Objetivo del proyecto

El objetivo de OINK es utilizar la tecnología para fomentar mejores hábitos de ahorro mediante una herramienta que permita registrar, visualizar y analizar información financiera de manera sencilla e interactiva.

👨‍💻 Proyecto académico

OINK integra conceptos de:

Programación + Bases de datos + Análisis de datos + Educación financiera + IoT + Inteligencia de voz
